Brand direction guide · v0.1

Structure under controlled transformation.

Forma is a structured visual system for agent-driven design. The identity should feel calm, precise and constructed—not magical, futuristic or generically “AI”.

●
This guide defines direction, not a final UI specification.Examples communicate hierarchy, rhythm, semantics and visual behavior. Coding agents should adapt layouts and component details to the product context instead of reproducing these examples pixel-for-pixel.
01 / Idea

What should Forma feel like?

The product gives structure to visual ideas. Its identity comes from tension between a stable system and an element that is actively being shaped.
01

Structure

Neutral surfaces, deliberate spacing and strong hierarchy. The interface should feel organized before it feels expressive.

02

Controlled transformation

Curves, handles and tension can suggest that a form is being manipulated. Avoid decorative distortion without purpose.

03

Active signal

Orange is semantic. It means active, selected, transforming or a high-value action—not “add some color here”.

03 / Color

Dark-first, warm-neutral.

Dark is the default environment. Light exists as an intentional alternate mode, not as the canonical presentation. Avoid blue-purple AI palettes and cold neutral systems.
Forma Ink#171717

Primary dark environment and core structure.

Forma Paper#F4F1EA

Primary light surface, canvas and reversed foreground.

Forma Signal#FF5A36

Active, selected, transforming and primary action states.

Forma Graphite#62605C

Support tone. Do not rely on it as low-contrast text on Ink.

Orange ruleUse Signal sparingly. If everything is orange, nothing is active. It may highlight a selected layer, transform handle, agent action, important CTA, focused control or progress state.
04 / Typography

Quiet typography, expressive geometry.

The logo carries the unusual form. Typography should stay restrained and highly readable so the interface does not compete with the mark.

Design should feel constructed, not decorated.

Prefer Geist for UI and product communication. Use a compact, clear hierarchy. Avoid overly futuristic display faces, excessive uppercase, or typographic effects that make the product feel like generic AI software.

05 / Visual language

Show how forms are made.

Secondary graphics can borrow from vector construction: control points, Bézier tension and selected objects. These are motifs, not mandatory decorations on every screen.

Control points

Nodes define structure. One active node may carry Signal orange when a transformation is happening.

Bézier tension

A useful motion and illustration language. Keep it minimal so it reads as construction rather than a tutorial diagram.

Selected state

The editor itself can echo the brand: active handles and selected layers naturally give Signal a functional role.

07 / Guidance

What agents should preserve.

Treat the brand as a set of visual principles. Preserve semantics and character; adapt implementation details to the actual workflow.

Do

✓Default to a dark product environment with warm neutral surfaces.
✓Use Signal orange for active, selected, transforming and primary-action states.
✓Keep typography quiet and let geometry carry more of the personality.
✓Use construction motifs selectively: nodes, paths, handles and tension.
✓Adapt spacing, component dimensions and layouts to usability and context.

Don't

×Do not turn the product into a wall of orange accents.
×Do not introduce purple/blue “AI” gradients, sparkles, glows or magic motifs.
×Do not recreate or mutate the approved logo geometry in product code.
×Do not treat sample components in this document as mandatory pixel specs.
×Do not make every surface heavily rounded, glossy or decorative.

Instruction block for a coding/design agent

This text can be copied into project guidance. The HTML remains the richer visual reference.

Forma is dark-first and warm-neutral. Use #171717, #F4F1EA and #FF5A36 as the core identity colors. Orange has semantic meaning: active, selected, transforming, focused or high-value action. Keep its use sparse.

Use Geist as the primary product type direction. Typography should be clear and restrained. The brand personality comes primarily from structured geometry, tension, control points and vector-construction motifs—not decorative type or generic AI effects.

Treat examples in this guide as visual-direction references, NOT pixel-perfect implementation requirements. Adapt component dimensions, spacing, layout and derived surface colors to product usability and accessibility while preserving the brand's hierarchy and character.

Prefer dark mode as the canonical product experience. Provide a thoughtful light alternative using warm Paper rather than pure white.

Avoid purple/blue AI gradients, sparkles, glow-heavy interfaces, neural-network imagery, generic SaaS abstractions, excessive orange, and arbitrary modifications to the supplied logo assets.
