MCP is a standard way for an AI app to use tools in another app.

Your AI app can create and edit designs in your Forma workspace, and you see them here.

Your MCP URL

Use the same URL in each app you want to connect.

https://forma.example/mcp/personal

Example URL for this prototype.

Pick your app

Claude

  1. In Claude, add a custom connector.
  2. Paste your Forma MCP URL.
  3. Open the browser approval page and approve access to your Forma workspace.

Do not paste a token. This connection needs none.

What to expect: Forma’s tools become available in Claude. The designs you create or edit appear in your Forma workspace.

ChatGPT and Codex

  1. Open the app’s own MCP connection flow.
  2. Paste the same Forma MCP URL.
  3. Follow its approval flow, then return to your conversation.

These app flows accept OAuth or no authentication. A pasted personal access token will not work here.

What to expect: the app can use Forma’s design tools, and you see its changes in your workspace.

Command-line tools

Codex CLI, Claude Code and Gemini CLI

  1. Create a personal access token below.
  2. Provide your MCP URL and token in your tool’s MCP configuration.
  3. Restart or reconnect the tool, then ask it to create or edit a Forma design.

For this command-line setup, use a token instead of browser approval. Keep the token in an environment variable.

Example · Codex CLI configuration

[mcp_servers.forma]
url = "https://forma.example/mcp/personal"
bearer_token_env_var = "FORMA_ACCESS_TOKEN"

Set FORMA_ACCESS_TOKEN to your key in the tool’s environment. Other tools use their own configuration format.

What to expect: the tool uses your token to access Forma’s design tools. Designs and edits appear in your workspace.
